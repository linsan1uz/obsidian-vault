## 核心原理

慢动作的本质是 **高帧率采集 + 低帧率编码**：

| 参数 | 值 | 说明 |
|------|-----|------|
| 采集帧率 (Capture Rate) | **120 fps** | 传感器每秒采集120帧 |
| 编码帧率 (Output Frame Rate) | **30 fps** | 写入文件每秒30帧 |
| 慢放倍数 | **4x** | 120/30 = 4倍慢动作 |
| 分辨率 | 1280x720 (HD) 或 1920x1080 (FHD) | 仅16:9 |
| 相机 | 仅后置 | 不支持前置 |

---

## 状态机流程

```
StateSlowMotionPreviewing (预览, 120fps)
    │ 按下快门
    ▼
StateSlowMotionPrepareRecording (准备录制)
    │ MediaRecorder配置完成, 开始录制
    ▼
StateSlowMotionRecording (录制中, 不显示录制时间)
    │ 松开快门 / 按停止键
    ▼
StateSlowMotionVideoStopping (停止录制)
```

完整状态链：

```
StateInit → StateResume → StateCameraOpened → StateSlowMotionPreviewing →
StateSlowMotionPrepareRecording → StateSlowMotionRecording →
StateSlowMotionRecordingPause (可选) → StateSlowMotionVideoStopping →
StateCameraReleasing → StateCameraReleased → StateStopped → StateNone
```

## 与普通录像的关键差异

| 对比项 | 慢动作 | 普通录像 |
|--------|--------|----------|
| 采集帧率 | 120 fps | 与输出帧率一致 (30/60) |
| 输出帧率 | 30 fps | 与采集帧率一致 |
| 分辨率 | 仅 720p/1080p 16:9 | 支持多种比例和分辨率 |
| SEF标记 | `SEF_RECORDING_MODE_SLOW_MOTION = 15` | `SEF_RECORDING_MODE_NORMAL = 0` |
| 音频采样率 | 12kHz | 48kHz |
| 音频码率 | 128kbps | 256kbps |
| GL录制 | 禁用 | 可选启用 |
| 录像中拍照 | 不支持 | 支持 |
| 录制时间UI | 不更新 | 实时更新 |
| Camera Session | `SESSION_REGULAR` | 根据fps/vendor模式决定 |
| 相机 | 仅后置 | 前后置 |
| 存储类型 | `SLOW_MOTION_VIDEO` | `VIDEO` |

### 5. 准备录制（核心）— StateSlowMotionPrepareRecording

**文件**: `main/src/main/java/com/ts/camera/presenter/state/video/slowmotion/StateSlowMotionPrepareRecording.java`

```java
public class StateSlowMotionPrepareRecording extends StatePrepareRecording {

    @Override
    public void entry(Object... objects) {
        ViewDisplayDependency.State.RECORDING.setEnable(true);
        // ① 录制类型 = SLO_MO
        RecorderParameter.RecordeType recordingType = RecorderParameter.RecordeType.SLO_MO;
        // ② 视频尺寸 = HD_SLO_MO (1280x720, 120fps)
        VideoSize videoSize = VideoSize.HD_SLO_MO;
        // ③ 存储类型 = SLOW_MOTION_VIDEO
        VideoSavePathWrapper videoSavePathWrapper =
            mStorageManager.enqueueVideoStorageBundle(
                buildVideoStorageBundle(IntentParser.get().getOutputUri(),
                    videoSize.getCameraApi2Value()));
        // ④ 构建录制参数
        RecorderParameter.Builder builder = getRecordParameterBuilder(
            videoSavePathWrapper, recordingType, videoSize, null);
        RecorderParameter parameter = builder.build();
        // ⑤ 准备录制
        mVideoRecording.prepareRecording(parameter);
    }

    @Override
    protected BasicStorageBundle buildVideoStorageBundle(Uri saveUri, Size videoSize) {
        return new BasicStorageBundle()
            .setSaveFileType(SaveFileType.SLOW_MOTION_VIDEO)  // ← 慢动作专用文件类型
            .setStorageType(mSettingsManager.getCurrentStorageType())
            .setExtraOutput(saveUri)
            .setDateTaken(System.currentTimeMillis())
            .setMimeType(MediaSavingConstants.MEDIA_TYPE_MPEG4_MIME)
            .setSize(videoSize);
    }

    @Override
    protected RecorderParameter.Builder getRecordParameterBuilder(
            VideoSavePathWrapper videoSavePathWrapper,
            RecorderParameter.RecordeType recordingType,
            VideoSize videoSize, Uri saveUri) {
        RecorderParameter.Builder builder =
            super.getRecordParameterBuilder(videoSavePathWrapper, recordingType, videoSize, saveUri);
        builder.setRecordingByGL(false);  // ← 禁用GL录制
        // GPS位置信息
        if (mSettingsManager.getParameterValue(ParameterKey.GEO_LOCATION) == GeoLocation.ON) {
            Location location = mLocationManager.getCurrentLocation();
            if (location != null) {
                builder.setRecorderLocation(location);
            }
        }
        return builder;
    }

    @Override
    public void handleVideoEvent(VideoEvent msg, Object... objects) {
        switch (msg) {
            case EVENT_RECORDER_START_PREPARE:
                mSoundPlayer.play(SoundType.TYPE_RECORDING_START);
                mMode.onPlayVibrationFB();
                break;
            case EVENT_VIDEO_SESSION_PREPARED:
                if (mVideoRecording.hasPreparedSession()) {
                    changeTo(StateSlowMotionPreviewing.getInstance());
                }
                break;
            case EVENT_RECORDING_STARTED:
                changeTo(StateSlowMotionRecording.getInstance()); // → 录制中
                break;
            default:
                super.handleVideoEvent(msg, objects);
                break;
        }
    }
}
```

protected RecorderParameter.Builder getRecordParameterBuilder(
        VideoSavePathWrapper videoSavePathWrapper,
        RecorderParameter.RecordeType recordingType,
        VideoSize videoSize, Uri saveUri) {

    // ... 省略其他参数设置 ...

    int fps = videoSize.getFps();  // 慢动作 = 120

    builder = new RecorderParameter.Builder(profile);

    // ★★★ 核心: 双帧率设置 ★★★
    if (recordingType == RecorderParameter.RecordeType.SLO_MO) {
        builder.setFrameRate(30);    // 输出编码帧率 = 30fps
    } else {
        builder.setFrameRate(fps);   // 普通视频: 输出帧率 = 采集帧率
    }
    builder.setCaptureRate(fps);     // 采集帧率 = 120fps

    // ... 其他设置 ...

    builder.setRecordingByGL(isGLRecording());  // 慢动作时返回false
    builder.setRecordeType(recordingType);
    return builder;
}

// isGLRecording() 中慢动作返回false:
protected boolean isGLRecording() {
    if (SizeUtil.isMultiWindow()
            || IntentParser.get().isMMSVideoEntry()
            || getCurrentMode() == CaptureMode.MODE_TIME_LAPSE
            || getCurrentMode() == CaptureMode.MODE_SLOW_MOTION  // ← false
            || (getCurrentMode() == CaptureMode.MODE_VIDEO && isFrontCamera()
            && !((instance.isFilterOn() || instance.isBeautyFaceOn()
            || instance.isVideo60Fps() || instance.isEisOn())))) {
        return false;
    }
    return true;
}

### 7. 录制中状态 — StateSlowMotionRecording

**文件**: `main/src/main/java/com/ts/camera/presenter/state/video/slowmotion/StateSlowMotionRecording.java`

```java
public class StateSlowMotionRecording extends StateVideoRecording {
    private boolean isShutterButtonDown;

    private StateSlowMotionRecording() {
        startTime = System.currentTimeMillis();
    }

    public long recordingTimeMS() {
        return System.currentTimeMillis() - startTime;
    }

    @Override
    public void handleViewEvent(ViewEvent event, Object... objects) {
        switch (event) {
            case VIEW_EVENT_CAPTURE_BUTTON_DOWN:
                isShutterButtonDown = true;
                break;
            case VIEW_EVENT_CAPTURE_BUTTON_UP:
                if (!isShutterButtonDown) return;
                changeTo(StateSlowMotionVideoStopping.getInstance()); // → 停止
                isShutterButtonDown = false;
                break;
            case VIEW_EVENT_VIDEO_PAUSE_RESUME_BUTTON_CLICK:
                if (recordingTimeMS() < 500L) return;  // 500ms防抖
                changeTo(StateSlowMotionRecordingPause.getInstance()); // → 暂停
                break;
            default:
                super.handleViewEvent(event, objects);
                break;
        }
    }

    @Override
    public void handleVideoEvent(VideoEvent msg, Object... objects) {
        switch (msg) {
            case EVENT_UPDATE_RECORDING_TIME:
                break;  // ★ 慢动作不更新录制时间UI
            default:
                super.handleVideoEvent(msg, objects);
                break;
        }
    }

    @Override
    public void handleVolumeKeyEvent(SystemKeyEvent event, Object... objects) {
        switch (event) {
            case EVENT_KEYCODE_VOLUME_UP:
            case EVENT_KEYCODE_VOLUME_DOWN:
            case EVENT_KEYCODE_LONG_PRESS_UP:
                if (getVolumeKeyValue() == VolumeKeyControl.CONTROL_CAPTURE) {
                    changeTo(StateSlowMotionVideoStopping.getInstance());
                } else {
                    super.handleVolumeKeyEvent(event, objects);
                }
                break;
            case EVENT_KEYCODE_CAMERA:
                changeTo(StateSlowMotionVideoStopping.getInstance());
                break;
            default:
                super.handleVolumeKeyEvent(event, objects);
                break;
        }
    }
}

public class StateSlowMotionVideoStopping extends StateVideoStopping {

    @Override
    public void exit() {
        playEndSounds();                                         // 播放结束音
        ViewDisplayDependency.State.RECORDING.setEnable(false);  // 关闭录制UI
        changeFlashState();                                      // 恢复闪光灯状态
        mOrientationController.triggerEvent();                   // 触发方向控制
    }

    private void changeFlashState() {
        ParameterValue<?> parameterValue =
            mSettingsManager.getParameterValue(ParameterKey.FLASH_VIDEO);
        if (parameterValue != null) {
            if (parameterValue.getParameterState() == ParameterValueState.TEMPORARY) {
                // 临时值恢复为原始值
                ParameterValue<?>[] options =
                    SettingUIConfig.getInstance().getOptions(ParameterKey.FLASH_VIDEO);
                for (int i = 0; i < options.length; i++) {
                    if (options[i].getParameterState() == ParameterValueState.ACTUAL) {
                        parameterValue.setParameterState(ParameterValueState.NORMAL);
                        options[i].setParameterState(ParameterValueState.NORMAL);
                        SettingUIConfig.getInstance().setValue(options[i]);
                        break;
                    }
                }
            }
        }
    }
}

public void prepare(RecorderParameter parameter) {
    if (parameter.getRecordeType() == RecorderParameter.RecordeType.SLO_MO) {
        // ① 写入SEF慢动作标记
        SEFUtil.writeVideoRecordingMode(mMediaRecorder, SEFUtil.SEF_RECORDING_MODE_SLOW_MOTION);

        mMediaRecorder.setAudioSource(MediaRecorder.AudioSource.MIC);
        mMediaRecorder.setVideoSource(MediaRecorder.VideoSource.SURFACE);

        CamcorderProfile profile = parameter.getProfile();
        mMediaRecorder.setOutputFormat(MediaRecorder.OutputFormat.MPEG_4);
        mMediaRecorder.setVideoEncoder(profile.videoCodec);
        mMediaRecorder.setVideoEncodingBitRate(profile.videoBitRate);

        // ② 输出帧率 = 30fps (来自CamcorderProfile)
        mMediaRecorder.setVideoFrameRate(profile.videoFrameRate);
        // ③ 采集帧率 = 120fps (来自VideoSize.getFps())
        mMediaRecorder.setCaptureRate(parameter.getCaptureRate());

        mMediaRecorder.setVideoSize(parameter.getVideoWidth(), parameter.getVideoHeight());

        // ④ 音频: 低采样率 + 低码率
        mMediaRecorder.setAudioEncoder(MediaRecorder.AudioEncoder.AAC);
        mMediaRecorder.setAudioSamplingRate(12000);       // 普通=48000
        mMediaRecorder.setAudioChannels(2);               // 立体声
        mMediaRecorder.setAudioEncodingBitRate(128000);   // 普通=256000

    } else {
        // 普通视频/延时摄影录制配置 ...
    }

    // 公共设置: 输出文件、GPS、方向、时长限制、文件大小限制
    if (parameter.getParcelFileDescriptor() != null) {
        mMediaRecorder.setOutputFile(
            parameter.getParcelFileDescriptor().getFileDescriptor());
    } else {
        mMediaRecorder.setOutputFile(parameter.getFilePath());
    }
    if (parameter.getRecorderLocation() != null) {
        mMediaRecorder.setLocation(
            (float) parameter.getRecorderLocation().getLatitude(),
            (float) parameter.getRecorderLocation().getLongitude());
    }
    mMediaRecorder.setOrientationHint(orientation);
    mMediaRecorder.setMaxDuration((int) parameter.getMaxDuration());
    mMediaRecorder.setMaxFileSize(parameter.getMaxFileSize());
    mMediaRecorder.prepare();
}

// buildSessionRequest() 中根据fps决定session类型
Range<Integer> fps = get(CaptureRequest.CONTROL_AE_TARGET_FPS_RANGE);
int sessionType;

if (fps != null) {
    Integer lower = fps.getLower();
    if (lower >= 120) {
        sessionType = SessionConfiguration.SESSION_HIGH_SPEED;      // ≥120fps用高速session
    } else if (lower >= 60 && isVideo()) {
        sessionType = SESSION_OPERATION_MODE_VENDOR_START;
    } else if (mCaptureMode != null && mCaptureMode.isPhoto()) {
        sessionType = SESSION_OPERATION_MODE_VENDOR_PHOTO_START;
    } else if (mCaptureMode != null && mCaptureMode == CaptureMode.MODE_VIDEO) {
        sessionType = mIsVideoEis
            ? SESSION_OPERATION_MODE_VENDOR_VIDEO_EIS_START
            : SESSION_OPERATION_MODE_VENDOR_VIDEO_START;
    } else {
        sessionType = SessionConfiguration.SESSION_REGULAR;
    }
} else {
    sessionType = SessionConfiguration.SESSION_REGULAR;
}

// ★ 慢动作强制使用普通session (虽然fps=120)
// 实际高帧率由MTK平台SMVR vendor tag处理
if (mCaptureMode != null && mCaptureMode == CaptureMode.MODE_SLOW_MOTION) {
    sessionType = SessionConfiguration.SESSION_REGULAR;
}

request.setSessionType(sessionType);
```
